# Deprecated: replaced by gitgate

This project is no longer maintained. It was merged into **gitgate**: https://github.com/leasegate/gitgate

gitgate keeps what this tool did -- git and gh with the right identity chosen by directory -- and no longer leaves the SSH keys and GitHub tokens in files and environment variables: they are held by a tray app and released per process, after a human has approved the request, for a limited time.
